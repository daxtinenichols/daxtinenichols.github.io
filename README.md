# daxtinenichols.github.io

Free public home for two Catholic web pages:

- **Tree of Life** (https://daxtinenichols.github.io/): big questions about God, Jesus and the Church, one at a time, with real sources.
- **Your First Mass** (https://daxtinenichols.github.io/first-mass/): a gentle, step-by-step guide for anyone going to Mass for the first time.

The pages are built in the project folder and copied here with `site-deploy/build_site.py`. Edit the sources there, rebuild, and push to `main`; GitHub Pages publishes from `main`.
